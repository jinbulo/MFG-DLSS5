# FS4 MFG 更新说明

版本日期：**2026-10-05**（上一版：2026-10-04）
适用游戏：**Fallout 4 v1.10.163.0**（Steam 的次世代版 1.11.x 不能用，见第五节）

---

## 一、这一版变了什么（相对 2026-10-04）

### 1. 安装脚本改成中英双语

`install.bat` / `mfg-disable.bat` / `mfg-enable.bat` / `restore.bat` 背后都跑同一支
`mfg-tool.ps1`，它打印的每一句话现在都是中英对照：顶部说明、版本警告、取消提示、备份位置、
停用/启用结果、状态表（`on / 启用`、`off / 已停用(.off)`、`absent / 不在`）。

> `.bat` 本身保持纯英文注释 —— cmd 在非 UTF-8 代码页下显示中文会乱码；玩家实际读到的提示
> 都来自 `.ps1`，那部分已经是双语的。

### 2. 安装脚本能自己找到你的游戏

候选顺序：**① 拖拽/命令行给的目录 → ② 脚本所在目录与上一级 → ③ 上次装过的记录 →
④ Bethesda 注册表 → ⑤ 本机所有 Steam 库**。

第 ⑤ 条不只读主 Steam 目录，还会解析 `steamapps\libraryfolders.vdf`，所以你装在同一块盘
之外的第二块 Steam 盘上的游戏也找得到。机器上有多份游戏时会把它们列出来让你选。

### 3. 版本闸门：版本不对就不装

装之前读目标目录里的 `Fallout4.exe` 版本号。不是 `1.10.163.*` 会打印警告，并要求你
**手动输入 `yes`**；直接回车就是取消，**游戏目录一个字节都不会动**。

### 4. 受保护目录自动提权

目标目录写不进去时（典型的 `C:\Program Files (x86)\Steam\...`），脚本会自己用管理员身份
重开一次。

### 5. 两个修复

- 你用拖拽或命令行明确指定游戏目录时，**不再弹"选哪个游戏"菜单**（以前只要机器上有两份
  游戏就会问，非交互环境下会直接变成"找不到游戏目录"）；
- `mfg-disable.bat` 打印的文件清单分隔符修好了（以前会连在一起）。

### 6. 一键停用补上一个漏网的插件

`dlss5-lab-overlay.addon64` 以前不在停用名单里 —— 也就是说你按了"一键停用"，这个诊断覆盖层
**还在加载**。现在它和其他 5 个入口一起改名，停用是彻底的。

### 7. 必须用**无边框窗口**（新增，重要）

实测两次对照：游戏跑**独占全屏**时，本层要建的第二个交换链会失败
（`CreateSwapChainForHwnd -> 0x887a0001 = DXGI_ERROR_INVALID_CALL`），连续失败 3 次后本层
会主动放弃、保持游戏原状；改成**无边框窗口**后一次就成功。

原因是 DXGI 不允许给同一个窗口再建一个交换链，独占全屏下尤其不行，而本层正是"在同一个窗口
上接管呈现"。

**怎么改**：编辑 `文档\My Games\Fallout4\Fallout4Prefs.ini`

```ini
[Display]
bBorderless=1
bFull Screen=0
```

无边框模式下窗口填不满屏幕的话，进游戏 **设置 → 显示 → 分辨率** 选你的屏幕原生分辨率。

### 8. ENB 是必需的（新增结论，重要）

和天际那边同一个结论：**运动矢量是靠 ENB 在场才出来的**。同一台机器、同一套文件、同一支
addon，唯一差别是有没有装 ENB：

| | 没装 ENB | 装了 ENB 0.496 |
| --- | --- | --- |
| 接管 / 4 倍帧生成 | 正常 | 正常 |
| `dlss5-feed` MV 探针 | `0.000 px，0% 非零`（两次运行都一样） | **连续 6 个探针 100% 非零**，数值随转镜头 0.016 → 2.07 → 3.61 → 20.13 px |

没 ENB 时接管和 4× 照跑，但 DLSS-G 拿不到运动矢量，插值帧会拖影——所以 **ENB 不是可选项**。
本包仍然**不附带** ENB（授权原因），请自行到 enbdev.com 下载：游戏 **1.10.163 用 ENB 0.496**，
1.11.x 用 0.501。装好后本包不会覆盖你的 `d3d11.dll` / `enbseries.ini` / `enblocal.ini`。

> 注意：ENB 的 `enblocal.ini` 有 `[LIMITER] EnableFPSLimit`，某些版本默认是 `true`（61 帧），
> 那会把基础帧率钉死、插帧看起来"没效果"。测试前确认它是 `false`。

### 9. **1.11.240（Steam 次世代版）现在也支持了**（新增结论）

实测环境：游戏 **1.11.240** + **F4SE 0.7.9** + **ENB 0.501** + **无边框窗口**，结果和 1.10.163
一样是全通的：

```
OURSC | 建立我们自己的 D3D12 FLIP 交换链 -> 0x0 成功
DONE  | 已接管窗口（第 150 次 Present）
MFG 实测 | 屏幕约 164 帧/秒；应用侧约 41 帧/秒；实测倍数=4
MV probe  | frame1200 = 41.715 px, 100% 非零 | frame1800 = 35.089 px, 100% 非零
UIEXACT   | 覆盖 99.9% / 62.3%（HP/AP、罗盘、准心、底边都检测到并还原）
```

**三个前提缺一不可**：① F4SE **0.7.9**（1.11.240 专用的那个）；② ENB **0.501**（0.496 是给旧版的）；
③ **无边框窗口**——1.11.240 上如果切成独占全屏，接管会在 STEP4 以 `0x887a0001` 失败并放弃。

已知限制：`Data\F4SE\Plugins\fs4mvcam.dll` 是按 0.6.23 的插件接口编的，**F4SE 0.7.9 会拒绝加载它**
（日志 `plugin fs4mvcam.dll (00000000 00000000) no version data`）。但实测**不影响**：1.11.240 上
运动矢量由 ENB + 引擎自己的缓冲提供，探针照样 100% 非零。

| 脚本扩展 | 1.10.163 → **F4SE 0.6.23**；1.11.240 → **F4SE 0.7.9**（版本必须配对，否则 loader 直接拒绝） |

## 三、怎么装

**A. 不用 MO2（推荐，用脚本，会自动备份）**

1. 把压缩包解到一个**游戏目录之外**的地方（桌面就行）；
2. 双击 `install.bat`，或者把你的游戏目录拖到 `install.bat` 上；
3. 它会自己找游戏目录、**先把要被覆盖的同名文件备份到 `MFG-backup-<时间戳>\`**，再复制进去。

包里的 `Data\F4SE\Plugins\fs4mvcam.dll` 会被自动放进 `<游戏目录>\Data\F4SE\Plugins\`，
不用手动搬。

**B. 用 MO2**

把包里的文件复制进 `MO2\overwrite\Root`（= 游戏根目录）即可。

## 四、怎么启动

**用 `f4se_loader.exe` 启动**（包里新增的 `launch-f4se.bat` 就是干这个的，双击即可）。
注意 `f4se_loader.exe` 要和游戏版本配对：1.10.163 用 0.6.23 的 loader，1.11.240 用 0.7.9 的。

**1.10.163 时不要点 Steam 的"开始游戏"**：Steam 会先把它更新回 1.11.240。请在 Steam 库里把
Fallout 4 的更新策略设成 **属性 → 更新 → "仅在我启动此游戏时更新"**，并且始终用
`f4se_loader.exe` 进游戏。

**1.11.240 时两种都行**：点 Steam 的"开始游戏"或双击 `f4se_loader.exe` 都可以（已经是最新版，
不存在被"更新坏"的问题）。但**仍然必须是无边框窗口**。

## 五、游戏是 1.11.x（版本不对）怎么办

1.11.240 是 Steam 的次世代更新，它同时改了：可执行文件、F4SE 接口、以及**档案格式**
（BA2 头从 `BTDX v1` 变成 `v7/v8`）。所以对本层来说 1.11.240 不是"有点不兼容"，而是
**整条链都跑不起来**；而且**只换回旧的 `Fallout4.exe` 是不行的**（旧 exe 读不了新档案，
游戏直接起不来）。

要回到 1.10.163，必须用 Steam 控制台把整份旧数据下回来。命令、落点、覆盖步骤、事后清理，
见包内的 **`DOWNGRADE-to-1.10.163.md`**：

```
download_depot 377160 377162 5847529232406005096
download_depot 377160 377161 7497069378349273908
download_depot 377160 377163 5819088023757897745
download_depot 377160 377164 2178106366609958945
```

降级之后有一个**必须做的清理**：`Data\` 里会剩下次世代带的 Creation Club 文件
（`cc*.esl` / `cc*.ba2`）、`Fallout4 - TexturesPatch.ba2` 和 `Fallout4IDs.ccc`。它们有的是
`BTDX v7/v8`，而 1.10.163 的引擎读不了，**会让游戏在启动阶段直接挂掉**。实测就是：把这
26 个文件移走之后，本层的接管立刻从"失败"变成"成功"。

## 六、怎么停用 / 还原

| 想做的事 | 双击 |
| --- | --- |
| 暂时不要这一层（随时能开回来） | `mfg-disable.bat` |
| 开回来 | `mfg-enable.bat` |
| 彻底卸载、把安装前的文件放回去 | `restore.bat` |

用 `install.bat` 装过之后，这四个脚本也会被复制到 `<游戏目录>\MFG-tools\`，以后不用再找
压缩包。`restore.bat` 不会删掉备份目录，确认没问题后你可以自己删。

## 七、注意事项

1. **1.10.163 与 1.11.240 都支持**，但要按第二节的表配对（F4SE 0.6.23/0.7.9、ENB 0.496/0.501）。
   1.10.163 时别让 Steam 自动更新。
2. **必须无边框窗口**，独占全屏下本层会放弃接管（第一节第 7 条）。
3. **只从 `f4se_loader.exe` 进游戏**，别点 Steam 的开始按钮，也别让 Steam 自动更新。
4. **F4SE 版本要配对**：1.10.163 → F4SE 0.6.23；1.11.240 → F4SE 0.7.9（只有 Nexus 上有，
   而且装了也没用，因为本层在 1.11.240 上跑不起来）。
5. **ENB 是必需的**（`d3d11.dll` / `enbseries.ini` / `enblocal.ini` 本包都不动、也不带）。
   请自行安装（1.10.163 → ENB 0.496，1.11.x → ENB 0.501）；你自己的 ENB 照常运行。
   没 ENB 时虽然能接管、能出 4 倍帧，但**没有运动矢量、转镜头会拖影**。
6. **`ui_exact` 默认开启**：HUD / 字幕 / 数据条不进 DLAA，保持原像素。万一 HUD 出现异常，
   先把 `fs4mfg.ini` 里的 `ui_exact` 改成 `0` 对比一次，并把 `fs4mfg.log` 发给作者。
7. `hudless_tag` 只接受 `0/1`（写 ≥2 会被钳回 1 并在日志里说明）—— 2/3 那条路已经删除，
   两次实测都是负收益。
8. 关掉 **NVIDIA Smooth Motion**（它会和本层的帧生成抢同一条呈现路径）。
9. 想调帧数倍率：`fs4mfg.ini` 的 `mfg_frames`（1 = 2x，2 = 3x，3 = 4x … 5 = 6x）。
10. 左上角的黄字帧数窗口是调试用的，`fs4mfg.ini` 里 `stats_window=0` 可关。

## 九、日志在哪（排错用）

都在**游戏根目录**，出问题把这几份一起发给作者：

| 文件 | 看什么 |
| --- | --- |
| `fs4mfg.log` | 本层：接管是否成功、`slInit`、帧数/倍率、`ui_exact` 统计、深度与运动矢量 |
| `dlss5-feed.log` | DLSS5 喂帧：工作分辨率、运动矢量探针、深度探针、GPU 耗时 |
| `ReShade.log` | ReShade 本体与 RenoDX：依赖链、`NR-VERDICT`、效果编译 |
| `sl.log` | Streamline / DLSS-G：`slInit`、钩子、`shouldInterpolate` |
